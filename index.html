        Telefon & Bilgisayar Senkronizasyonu

        Güvenli Bulut: Kasa şifresi belirlediğinizde GitHub Gist üzerine giden veriler AES-256-GCM ile şifrelenir; GitHub veya başka hiç kimse içeriğinizi okuyamaz.

        Token almak için: GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → gist kutucuğunu işaretleyip oluşturun.

        Önce GitHub Gist veya Özel Bulut sekmesinden senkronizasyonu aktif edin; ardından telefonunuzu bağlayacak güvenli eşleştirme kodu burada oluşacaktır.
        Sıfır Üçüncü Taraf Sızıntısı

        Eşleştirme kodunuz hiçbir harici QR sunucusuna gönderilmez. Kasa şifresi aktifken aşağıdaki eşleştirme linki ve kodu AES-256-GCM ile şifrelenir; şifrenizi bilmeyen biri linki ele geçirse bile tokenınıza erişemez.

        Firebase Realtime Database (ör. https://proje-default-rtdb.firebaseio.com/depokutusu.json) veya GET / PUT destekleyen herhangi bir JSON REST adresi kullanabilirsiniz.
        Tüm kutucuklarınızı, notlarınızı, linklerinizi, paragraflarınızı ve resimlerinizi tek bir .json dosyası olarak indirebilir veya geri yükleyebilirsiniz.

        Telefonuna Uygulama Olarak Kur

        Android (Chrome): Sağ üstteki ⋮ menüsüne dokunup "Ana ekrana ekle" veya "Uygulamayı yükle" seçeneğini seçin.

        iPhone / iPad (Safari): Alt bardaki Paylaş simgesine dokunun ve "Ana Ekrana Ekle" deyin.

        Masaüstü (Chrome / Edge): Adres çubuğunun sağındaki Yükle simgesine tıklayın.

        Üst Düzey Güvenlik & Şifreleme

        Şifreniz hiçbir diske veya buluta kaydedilmez. Verileriniz PBKDF2-SHA256 (250.000 tur) ve AES-256-GCM ile şifrelenir. Şifreyi unutursanız kimse verilerinizi kurtaramaz.
